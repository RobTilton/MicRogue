# Workshop Assets
Updated: 2026-10-01

WorkshopAssets contains durable, reusable project inputs that are not yet Production-owned runtime content.

- [Fantasy Sprite Catalog](FantasySpriteCatalog/README.md): packed atlas, 486-entry catalog, semantic metadata, typed Godot lookup, and validation.

Each package owns its current contract and validation. Task history and exploratory evidence belong in Rooms; reusable tooling belongs in ToolShed. Moving a package into Production requires separate authorization.
